# LamUI

## Installation

1. Download the repository using **Code → Download ZIP**.
2. Extract the archive.
3. Open the project folder.
4. Install the required dependency:

```bash
pip install customtkinter
```

## Launch

Run `main.py`:

```bash
python main.py
```

## Requirements

- Windows 10 or newer
- Python 3.10+
- CustomTkinter 6.0.0+

## Project Structure

```text
LamUI/
└── main.py
```

## Notes

LamUI is a graphical interface for Windows applications. It does not replace an operating system.

The project is based on LamOS and uses Python with CustomTkinter.
